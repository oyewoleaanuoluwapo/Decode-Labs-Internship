# DecodeLabs Data Analytics Internship Portfolio

An end-to-end data analytics project series demonstrating data sanitization, relational database design, advanced SQL querying, and interactive Power BI visual analytics.

##  Project Overview
This repository contains the complete technical execution and documentation across four core data analytics projects using an e-commerce transactional dataset (1,200 records).

* **Project 1: Excel Data Transformation & Spreadsheet Sanitization**
  * Applied cell data formatting, temporal ISO standardization (`YYYY-MM-DD`), and promotional field cleansing to establish `Clean Ecommerce Dataset.csv`.
* **Project 2: Relational Schema Architecture & SQL Server Ingestion**
  * Provisioned `DecodeLabs_EDA` in SSMS, engineered explicit DDL schemas (`DECIMAL(10,2)`, `DATE`, `VARCHAR`), executed `BULK INSERT`, and performed string sanitization (`TRIM()`).
* **Project 3: Advanced T-SQL Analytical Reporting**
  * Designed complex analytical queries using CTEs, window functions (`SUM() OVER()`, `DENSE_RANK()`), and aggregations in `DecodeLabs_Project3` ($1.26M revenue).
* **Project 4: Executive Power BI Dashboard & Data Visualization**
  * Built an interactive Power BI dashboard (`DECODELABS ECOMMERCE DATA VISUAL ANALYSIS`) featuring KPI cards, product revenue rankings, annual trends, and payment method donut charts.

## 🛠️ Tech Stack & Tools
* **Spreadsheet Processing:** Microsoft Excel
* **Database Management:** SQL Server Management Studio (SSMS) | T-SQL
* **Business Intelligence:** Microsoft Power BI
* **Documentation:** Markdown / Word
